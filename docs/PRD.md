## 1. 项目概述

### 1.1 产品愿景

PRISM 是一个「图像粒子化实验室」：用户拖入任意图片，系统将图片的颜色与明暗实时重建为数万个发光粒子，构成一幅可以**旋转、缩放、呼吸**的三维立体画。它把静态照片变成有生命、可互动的空间装置。

### 1.2 背景与问题

- 传统「图片像素化/马赛克」工具只有平面结果，缺乏空间感与情感反馈。
- 现有粒子效果站大多依赖固定素材，用户无法用自己的照片参与。
- 用户希望有一个**开箱即玩、零学习成本、结果惊艳**的轻量网页工具。

PRISM 的解法：**本地采样 + GPU 实时渲染**，让「自己的照片变成可动的粒子艺术品」这件事在浏览器里几秒内完成。

### 1.3 目标用户

| 用户画像 | 诉求 |
| --- | --- |
| 设计/创意从业者 | 为作品集、提案寻找独特的视觉化表达 |
| 普通用户 | 用宠物、风景、人像照片生成可分享的动态效果 |
| 前端/WebGL 学习者 | 参考一个完整的 Three.js 粒子管线范例 |

### 1.4 核心使用场景

1. 打开页面 → 看到内置示例（FLOWER SIGNAL）自动完成粒子揭示动画 → 被效果吸引。
2. 拖入自己的照片 → 2 秒内看到照片变成粒子浮雕 → 拖动旋转观察景深。
3. 切换「浮雕 / 波面 / 星尘」模式，调节景深、流动、粒径 → 找到满意的形态。
4. 点击「散开」制造粒子飞散的戏剧瞬间，再「聚合」收回。
5. 截图 / 录制分享（🔜 导出功能落地后为一键导出）。

### 1.5 核心价值

- **唯一性**：每张图片的颜色、明暗、轮廓决定了粒子的排布与深度，产出独一无二。
- **实时性**：全部交互（旋转/缩放/模式切换/参数调节）在 GPU 上即时反馈，无等待。
- **隐私性**：图片 100% 本地处理，不上传服务器；这项承诺放在 README 与帮助信息中，不让常驻标签干扰作品。

### 1.6 市场位置与机会

调研显示，图像粒子产品已经形成三条常见路线：展示型特效、全参数编辑器、带导出的创作工具。具体样本、证据与来源见 [`docs/MARKET_RESEARCH.md`](./MARKET_RESEARCH.md)。

PRISM 选择第四种组合：**作品优先的空间暗房**。它保留 3D 观看与导演式转场，把复杂参数压进预设和渐进面板，并补齐导出与配方复现。产品的核心循环调整为：

```
导入图像 → 自动显影 → 选择气质 → 少量微调 → 进入定格 → 导出作品/配方
```

优先级判断：

1. “作品可带走”高于增加更多模式，因此静态高清导出为当前最高优先级。
2. 自动图像适配高于更多裸参数，默认结果必须先好看。
3. 预设高于全参数面板，普通用户先选气质，高级用户再展开微调。
4. WebGPU 采用渐进增强；WebGL 继续作为稳定基线。

## 2. 产品定位与设计原则

### 2.1 设计独特性

PRISM 不是一个「工具面板 + 预览区」的常规工具，而是一个**沉浸式空间体验**：

| 原则 | 说明 | 落地方式（现状） |
| --- | --- | --- |
| D1 · 作品拥有独立舞台 | 中央画布是独立布局区域，任何常驻 UI 都不覆盖作品 | 左侧叙事、中央画布、右侧控制三栏结构 |
| D2 · 单一暖色信号 | 炭黑与暖灰构成主体，只用柔和铜粉标记当前状态和行动点 | `--accent: #cfb09b`，不使用多彩 UI 与霓虹外发光 |
| D3 · 质感来自光而非容器 | 用电影颗粒、暗部层次和粒子辉光营造材质，界面本身保持平面和克制 | 细分隔线、方角、留白；无大面积玻璃卡片 |
| D4 · 小文字建立尺度 | 文案只负责方向感，不在尺寸和亮度上与粒子竞争 | 标题 23–28px，说明 11px，桌面放在左侧中段 |
| D5 · 动效服务于变化 | 入场、换图、模式和散开都解释粒子如何从一种状态转为另一种 | GSAP 驱动 uniform；后续加入图片间连续重组 |
| D6 · 参数渐进出现 | 首层只选择气质，微调与画面参数按需展开 | 模式、预设常驻；滑杆与高级参数折叠 |

### 2.2 页面简洁性

| 原则 | 说明 | 落地方式（现状） |
| --- | --- | --- |
| S1 · 单一页面、零导航层级 | 所有创作功能在一屏完成 | 单页，无路由 |
| S2 · 默认隐藏、按需展开 | 参数面板默认收起；复杂设置不抢占首屏 | `inert` 保证隐藏面板不进入键盘路径 |
| S3 · 文字与图标共同消歧 | 桌面保留低对比文字；窄屏才收为图标 | 右侧纵向控制，触控目标不低于 44px |
| S4 · 一个主行动点 | 首屏只有「选择图片」承担导入 | 描边按钮 + 垂直加号，无斜箭头和磁吸 |
| S5 · 控件不遮挡主体 | 所有常驻控件位于画布之外 | CSS Grid 划分三栏，画布独立响应尺寸 |

### 2.3 情感化与细节

- 磁吸按钮（`magnetic`）：主按钮跟随光标轻微偏移，模拟「有引力」的质感。
- 光标粒子场：指针靠近时，粒子在其周围轻微起伏（`cursorField` 高斯衰减场）。
- 呼吸感：粒子自身持续缓慢起伏，即使无操作画面也「活着」。
- 状态反馈：导入有加载指示器（「正在重建图像」）、成功/失败有 toast、散开/暂停有 aria 状态同步。

### 2.4 本地优先与隐私

- 图片仅经 `createImageBitmap` / `Image` 在浏览器内解码，**不发起任何网络上传**。
- 🔜 未来新增导出功能同样保持本地完成（Canvas/Offscreen 渲染导出）。

### 3.2 F1 · 图片导入 ✅

| 项 | 需求 |
| --- | --- |
| 入口 | ① 左侧「选择图片」按钮；② 源图信息行的「替换」按钮；③ 拖拽文件到窗口任意位置；④ `Ctrl/Cmd + O`；🔜 ⑤ 粘贴板图片 |

| 非法输入 | 不支持的格式 toast「请选择 JPG、PNG、WEBP 或 AVIF 图片」；解码失败提示「无法读取这张图片」 |
| 拖放体验 | 拖入时全屏出现「松手，让它进入空间。」的磨砂遮罩（`.drop-layer`），含格式提示 |
| 处理反馈 | 解码+采样期间显示「正在重建图像」加载指示器 |

| 🔜 F1-1 | 利用 `createImageBitmap` 的方向处理并增加带方向测试夹具，P1 |
| 🔜 F1-2 | 粘贴导入（Ctrl+V 直接粘贴剪贴板图片），P1 |

### 3.3 F2 · 粒子重建管线 ✅

**流程**：解码 → 缩采样 → 暗部阈值分析 → 可见像素过滤 → 生成顶点属性数组 → 上传 GPU → 揭示动画。

| 环节 | 现状规则 |
| --- | --- |
| 采样上限 | 桌面 ≤ 23,500 像素点，移动端 ≤ 14,500；超限按宽高比等比缩采样 |
| 暗部过滤 | 计算图片四周 4% 边缘带的平均亮度：若 < 48，阈值 = min(72, 边缘均值 + 26)，剔除低于阈值的深色像素（避免纯黑背景变成一整片噪点粒子） |
| 保底策略 | 若可见像素 < 8%，放弃阈值，全量像素参与（防止深色照片被过滤干净） |
| 透明处理 | alpha ≤ 0.06 的像素剔除；透明图只保留主体轮廓 |
| 属性生成 | 每粒子：`position`（平面坐标）、`aOrigin`（球面起始点，用于揭示汇聚）、`aScatter`（散开方向）、`color`（RGB）、`aLuma`（亮度）、`aRandom`（随机因子）、`aEdge`（边缘强度，由右/下邻像素亮度差计算）、`aAlpha`（透明度，下限 0.18） |
| 揭示动画 | 载入后粒子从随机球面起点汇聚到目标位置，错峰 0–0.26 归一化随机延迟，1.25s 缓出（`reduced-motion` 下瞬时完成） |
| 资源管理 | 换图时旧 `geometry.dispose()`，避免显存泄漏 |

🔜 F2-1：采样移入 Web Worker，大图（30MB 级）采样不阻塞主线程，P1。
🔜 F2-2：增加「粒子密度」用户可选项（精致 / 均衡 / 轻盈三档），P2。
🔜 F2-3：批量导入（一次拖入多张，缩略图选择切换），P3。

### 3.4 F3 · 空间模式 ✅

三种模式通过 `uModes` 向量做**平滑插值切换**（GSAP 0.8s），而非瞬间跳变：

| 模式 | 粒子 Z 轴逻辑 | 视觉特点 |
| --- | --- | --- |
| 浮雕（默认） | 亮度越高越突出 + 边缘像素额外抬升（`reliefZ`） | 最接近原图的立体浮雕，信息保真度最高 |
| 波面 | 双频正弦/余弦波叠加（`waveZ`），随时间流动 | 画面如水面波动，动态感最强 |
| 星尘 | 每个粒子随机 Z 偏移（`dustZ`） | 解构感最强，画面化为一团星云 |

🔜 F3-1：新模式——「漩涡」（绕中心旋转场）与「流动」（沿亮度梯度方向流动），P2。
🔜 F3-2：双模式混合滑杆（如 70% 浮雕 + 30% 波面），P3。

### 3.5 F4 · 参数调节 ✅

参数面板默认收起，点击 dock 中「调整参数」展开（展开时点击面板外自动收起，`Esc` 也可收起）：

| 参数 | 范围 | 默认 | 说明 | 强调色 |
| --- | --- | --- | --- | --- |
| 景深 `uDepth` | 0 – 2 | 1.20 | 控制三种模式的 Z 轴幅度整体强弱 | 玫瑰色 |
| 流动 `uMotion` | 0 – 1 | 0.32 | 呼吸、漂移、波速、光标场的强度 | 蓝色 |
| 粒径 `uPointSize` | 0.55 – 1.8 | 1.10 | 粒子点的基础尺寸 | 鼠尾草绿 |

- 滑杆实时反馈（数值两位小数 + 轨道填充色跟随 `--fill`）。
- uniform 变化经 GSAP 0.24s 缓动，杜绝数值跳变。
- 🔜 F4-1：气质预设（内置/保存/命名/一键套用，存 localStorage），P1；产品层归入 F11。
- 🔜 F4-2：色温/饱和度/亮度调节，与「辉光强度」合并为第二组「画面」参数，P2。

### 3.6 F5 · 视角交互 ✅

### 3.7 F6 · 动画控制 ✅

- **散开 / 聚合**：点击后粒子沿各自的 `aScatter` 方向炸开（1.15s 缓出）或聚回（0.9s），按钮状态同步（icon + aria-pressed + tooltip 文案互换）。
- **暂停 / 继续**：冻结 `uTime` 累积（呼吸、波面、光标场全部静止），图标在 play/pause 间切换；`Space` 快捷键等效（焦点在输入框时不触发）。
- 🔜 F6-1：散开程度滑杆（0–100%），当前只有全散/全聚两态，P2。

### 3.10 F9 · 响应式与可访问性 ✅

- 桌面采用左侧叙事、中央作品、右侧控制；`≤1100px` 收窄侧栏，`≤767px` 改为顶部身份/导入、中央画布、右侧图标栏、底部源图信息；`max-height:600px` 压缩文字与间距，最小宽度 320px。
- 移动端专项：粒子采样上限下调（14,500）、像素比上限 1.25、辉光强度下调（0.34）、初始视角缩放适配。
- 可访问性：全部按钮带 `aria-label/aria-pressed/aria-expanded`；焦点态 2px 蓝色描边；状态播报走 `aria-live`；支持 `prefers-reduced-motion`（动画时长归零、粒子时间流速 ×0.08、揭示瞬时完成）。
- 🔜 F9-1：触屏双指缩放与单指旋转手势冲突处理，P1。

### 3.11 F10 · 捕捉与导出 🔜 P1

导出不是孤立按钮，而是一段从互动状态进入作品状态的流程：

1. 点击「定格」暂停时间并进入观赏模式，界面淡出但保留退出入口。
2. 用户可继续旋转/缩放构图，确认后导出 PNG 或 WebP。
3. 默认导出为当前画布的 2× 分辨率，上限受设备纹理尺寸与内存预算约束；失败必须恢复原渲染尺寸。
4. 文件名格式：`prism-{source}-{preset}-{timestamp}.{ext}`。
5. 可选下载 JSON 配方，记录模式、参数、旋转、缩放、质量档和 PRISM 版本；不包含原始图片数据。
6. 导出期间显示与画布形状一致的进度状态，完成后提供文件尺寸反馈。

验收：导出文件像素尺寸正确、无 UI、颜色与屏幕观感一致；连续导出不会改变交互状态或造成资源增长。

### 3.12 F11 · 气质预设 🔜 P1

- 内置四种气质：**显影**（保真浮雕）、**潮汐**（柔和波动）、**游离**（松散星尘）、**余烬**（低流动、高景深、暖色）。名称描述感受，详情页再说明参数。
- 切换预设必须连续插值，不瞬间跳变。
- 用户可保存最多 12 个本地预设，支持重命名、覆盖、删除和恢复默认。
- localStorage 数据带 schema version；解析失败时回退默认，不阻塞页面。
- 导入图片不会重置当前预设，除非自动适配检测到不可辨认结果并给出非强制建议。

### 3.13 F12 · 自适应质量 🔜 P1

- 三档用户可见质量：轻盈 / 均衡 / 精致；默认“自动”。
- 运行时采样最近 120 帧，在连续低帧率窗口内逐级降低 DPR、Bloom 与粒子采样目标；恢复需要更长稳定窗口，避免档位抖动。
- 使用 `renderer.info` 记录 draw call、points 与 geometry 数量作为诊断信息，不默认展示给普通用户。
- 自动降级只改变渲染成本，不改变用户选择的模式和艺术参数；状态变化以一次克制 toast 告知。
- WebGPU 作为实验增强通道，当前稳定版继续使用 WebGL，保证较广浏览器覆盖。

### 3.14 F13 · 连续重组 🔜 P2

- 换图时旧作品先沿当前模式的运动场解构，新作品复用粒子池并渐进重组，避免黑屏或硬切。
- 数量变化时优先复用已有粒子，多出的粒子从画面边缘/深处进入，减少 GPU 缓冲频繁分配。
- `prefers-reduced-motion` 下使用 120ms 交叉淡化，不执行空间飞散。
- 导入失败保留旧作品，不启动转场。

## 4. 粒子展示效果优化（核心章节）

### 4.1 视觉质量

| 优化点 | 现状实现 | 预期效果 / 待优化 |
| --- | --- | --- |
| V1 辉光 Bloom | UnrealBloomPass（桌面强度 0.48 / 移动 0.34，半径 0.58，阈值 0.2） | 粒子呈发光光点而非普通像素点；🔜 将辉光强度纳入参数面板「画面」组 |
| V2 电影级色调 | ACESFilmic 色调映射 + 曝光 1.06 + sRGB 输出 | 高光柔和、暗部不糊；🔜 提供 2–3 种色调预设（胶片/霓虹/黑白） |
| V3 加色混合 | `THREE.AdditiveBlending` + `depthWrite:false` | 粒子重叠处自然增亮，形成光斑层次 |
| V4 颜色提炼 | 片元着色器对颜色做 `pow(0.82)` 提亮 + 饱和度 ×1.32 | 原图颜色更浓郁通透，抵消暗背景的压抑感 |
| V5 边缘提亮 | 边缘粒子向暖白偏移 4.5%（`vEdge * 0.045`） | 主体轮廓像被光勾勒，强化「发光体」质感 |
| V6 软粒子形态 | 片元按到圆心距离做 core（78%）+ halo（22%）双段渐变 | 粒子边缘羽化，近看是光斑而非硬点 |
| V7 景深随视点 | `gl_PointSize` 含透视项 `11/max(1,-z)` | 近大远小，旋转时纵深层次真实 |

### 4.2 动效设计

| 优化点 | 现状实现 | 说明 |
| --- | --- | --- |
| M1 揭示仪式感 | 粒子从随机球面汇聚成图，错峰延迟 + 三次缓出，1.25s | 首次见到图片「从虚空中生长出来」，是产品记忆点 |
| M2 呼吸感 | Z 轴正弦呼吸 + X/Y 微漂移，速度随「流动」参数 | 静止时画面依然有生命；`uTime` 初值随机化避免每次刷新节奏相同 |
| M3 光标场 | 指针 2.35 世界单位半径内粒子隆起（高斯衰减） | 让用户觉得「光能被手指扰动」，强化可触摸感 |
| M4 阻尼系统 | 旋转/缩放/位置全部经 `THREE.MathUtils.damp` 指数阻尼 | 任何操作都不会生硬启停，手感接近惯性物理 |
| M5 模式插值 | 三模式共享一个 shader，`uModes` 向量做 0.8s 平滑插值 | 模式切换是「变形」而非「切换」，连续性远超多 shader 方案 |

| 优化点 | 现状实现 | 指标 / 待优化 |

## 6. 技术方案

### 6.1 技术栈与选型理由

| 技术 | 用途 | 理由 |
| --- | --- | --- |
| Vite 7 | 构建/开发服务器 | 原生 ES 模块、极快冷启动 |
| Three.js 0.179 | 3D 渲染 | `Points + ShaderMaterial + EffectComposer/UnrealBloomPass` 组合成熟 |
| GSAP 3.15 | 动画缓动 | uniform 数值动画、UI 转场、ScrollTrigger |
| Lucide | 图标 | 轻量、按需导入（`createIcons`） |
| 原生 JS | 逻辑 | 无框架负担，项目体量小（app.js 768 行） |

### 6.2 架构

```
index.html（UI 骨架，全部控件带 id/aria）
  └─ styles.css（设计系统变量 + 组件样式 + 三档断点）
  └─ app.js
       ├─ 渲染核心：renderer / scene / camera / composer(+bloom) / particleRoot
       ├─ Shader 层：自定义 vertexShader + fragmentShader（单材质三模式复用）
       ├─ 采样层：decodeFile → sampleImage → getDarkThreshold → buildParticles
       ├─ 交互层：pointer 旋转缩放 / wheel / drag&drop / keyboard / range 输入
       ├─ 状态层：paused / scattered / panelOpen / customImageLoaded / uReveal…
       └─ 动画循环：requestAnimationFrame → damp 收敛 → composer.render()
```

### 6.3 渲染管线数据流

```
图片文件
  → 解码（createImageBitmap / Image 回退）
  → 缩采样 canvas（≤23.5k/14.5k 像素）
  → getImageData 逐像素分析（亮度/边缘/透明度/暗部阈值）
  → 生成 8 个顶点属性 BufferAttribute
  → THREE.Points + ShaderMaterial 上传 GPU
  → 每帧：uniform 时间累积 → 顶点着色器（揭示/模式/呼吸/光标场/散开）
  → 片元着色器（软粒子/提亮/饱和/边缘暖化）
  → EffectComposer（RenderPass → UnrealBloomPass）
  → canvas 输出
```

### 6.4 目录结构（现状）

```
prism-image-particle-lab/
├─ index.html          # UI 骨架
├─ styles.css          # 设计系统 + 组件样式
├─ app.js              # 全部逻辑（渲染/采样/交互）
├─ public/
│  └─ flower-signal.png  # 内置示例图
├─ docs/               # PRD / 优化记录 / 提示词 / 视觉基线
├─ dist/               # 构建产物
└─ package.json        # dev / build / preview 脚本
```

🔜 6.4-1：app.js 按「采样 / shader / 交互 / UI」拆分为模块（当前单文件 768 行已达可维护性临界点），P1。

## 7. 交互规范与页面布局

### 7.1 桌面布局（>900px）

```
┌──────────────┬─────────────────────────┬──────────┐
│ PRISM        │                         │ 形态     │
│ 图像粒子实验 │                         │ 浮雕     │
│              │                         │ 波面     │
```

- 三列均由 CSS Grid 分配真实空间，侧栏不叠在 Canvas 上。

- 右侧控制纵向排列，参数直接在「调整」下方展开；侧栏自身可滚动，应对矮屏。
- z-index 仅用于纹理、拖放遮罩和状态反馈，不用大数值修补布局。

### 7.2 移动端布局（≤767px）

- 第一行是品牌信息与导入按钮，第二行是画布和 48px 右侧图标栏，第三行是源图信息。
- 参数展开时右栏增至 140px，画布同步收窄并由 `ResizeObserver` 重新适配构图。
- 所有触控按钮高度至少 44px；右栏可滚动；页面不依赖固定 600px 高度，因此 844×390 横屏也能使用。
