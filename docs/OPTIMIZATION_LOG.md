## 2026-09-05 · 02 / 布局与排版方案

- 问题：顶部玻璃导航、大号居中标题、底部控制条与粒子争夺空间；默认粒子为避让标题而下移。
- 方案：桌面使用左侧介绍/图像、中央独立画布、右侧操作的三列布局。控件不覆盖中央画布，粒子回到画布中心。
- 排版：缩小标题，压缩说明，保留可读的暖灰文字；只用一个克制的暖色强调。撤去玻璃容器、彩色按钮和无意义的标签。
- 操作：选择图片使用简洁加号；移除重复导入入口与“仅在本地处理”提示；模式名称保持可见，参数按需展开。
- 响应式：窄屏将介绍压缩到上方，操作保持右侧窄列，图片信息位于独立边缘区域；画布仍有自己的布局空间。
- 验证计划：保存真实改动前/后截图；检查桌面、平板、手机、矮窗口与横屏，回归图片导入、所有控件、键盘焦点和生产构建。

## 2026-09-06 · 03 / 三栏沉浸式工作台

- 将顶部导航、居中 Hero 和底部控制坞重排为左侧叙事、中央作品、右侧控制的三栏结构，中央粒子画布不再被界面覆盖。
- 标题收束为「让图像，成为光。」，字号降至 23–28px；说明缩为两行。去掉顶部重复导入入口、「仅在本地处理」标签和标题内嵌图片。
- 「选择图片」改为低对比描边按钮，右侧采用垂直加号，移除斜箭头和磁吸位移。
- 设计系统收束为炭黑、暖灰、柔和铜粉单强调色；去除大面积玻璃、圆角胶囊和彩色多强调，改用细线、留白和窄侧栏建立层级。
- 粒子依据中央画布独立尺寸渲染；默认回到垂直中心，镜头按可见粒子的实际包围盒和画布宽高比自动适配，透明边距不再导致主体过小。
- 移动端改为上方品牌/导入、中央独立画布、右侧图标控制、下方图像信息；参数展开时只拓宽右侧栏。矮横屏取消固定高布局，控制栏可在自身区域滚动。
- 参数面板收起时使用 `inert` 阻止键盘误入，关闭后焦点回到触发按钮；全局空格快捷键不再抢占按钮和表单控件，画布增加方向键旋转。
- 修复暗图回退时透明像素被误计入粒子数量的问题；完全透明图片现在给出明确错误。
- 一度尝试 `mix-blend-mode: screen` 提升粒子亮度，Chromium 实测导致透明 WebGL 画布合成为白色，已立即撤销并记录，未保留到交付代码。

## 2026-09-06 · 06 / F11 气质预设与本地收藏

- 新增四个内置气质：显影、潮汐、游离、余烬。每个气质同时编排形态、景深、流动和粒径，使用 0.72s 连续插值完成变化。
- 预设入口位于右侧栏最上方，视觉权重低于作品；桌面显示完整名称，移动端折叠时仍显示当前气质，不再出现无意义空白方块。
- 用户手动切换形态或参数后，选择器标记为「当前微调」，清楚区分预设与编辑状态。

## 2026-09-06 · 07 / 粘贴导入与双指缩放

- 支持直接粘贴剪贴板中的图片；焦点在输入框、文本域或可编辑内容时不劫持粘贴，其他剪贴板内容保持浏览器默认行为。
- 多指交互用 Pointer Events 统一实现：单指维持原有旋转，第二指加入后锁定起始距离与镜头距离，通过指距比例缩放；抬起一指后平滑回到单指旋转。
- 双指与滚轮使用同一套相对适配距离限制（0.55–1.8 倍），不同长宽比图片不会套用固定镜头边界。
- Canvas 发布只读的当前旋转目标和镜头距离数据属性，既便于自动化验证，也为后续无障碍状态说明和嵌入控制提供稳定观察点。
- 调整浏览器测试：行为验收默认不批量截图，视觉截图按需单独开启，避免 Windows headless Chromium 软件渲染器在大量 WebGL 截图后丢失上下文。
- 自动化新增剪贴板图片和两指缩放验证，最终 150/150 通过；生产构建通过。

## 2026-09-06 · 08 / F12 自适应质量

- 参数面板新增自动、轻盈、均衡、精致四档质量。自动默认以均衡开始；用户选择写入 `prism.quality.v1`，刷新后继续使用。
- 每档联合控制采样预算、桌面/移动 DPR 上限和 Bloom 强度，而不是只改变单一像素比：轻盈优先流畅，精致将桌面采样预算提高到 42,000 并允许 2× DPR。
- 自动模式按 120 帧窗口测量实际 FPS；持续低于桌面 48fps/移动 23fps 时逐级降档，高于目标并连续稳定四个窗口才恢复，避免档位来回抖动。
- 自动变化保持用户的形态、参数和源图，只重建粒子预算与渲染成本；降级/恢复以一次克制 toast 反馈。
- 质量切换使用 idle callback 安排重建，并用 pending 锁避免同时进行多次自动调整。
- 自动化验证精致与轻盈产生不同粒子预算且选择被持久化；全套 151/151 通过，生产构建通过。
